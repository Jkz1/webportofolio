1. RINGKASAN EKSEKUTIF
-----------------------
Project ini adalah website portfolio personal dengan karakter visual dark, teknikal, dan bergaya terminal/blueprint. Aplikasi dibangun menggunakan Next.js App Router, React, TypeScript, Tailwind CSS v4, Framer Motion, dan lucide-react.

Arsitektur deployment menggunakan static export Next.js. Halaman dikompilasi menjadi file HTML/CSS/JavaScript di folder out, kemudian disajikan oleh Nginx melalui multi-stage Docker build. Dengan konfigurasi saat ini, aplikasi tidak membutuhkan Node.js pada runtime production.

Fitur utama:
- Landing page portfolio satu halaman.
- Section Hero, About, Skills, Projects, Contact.
- Halaman detail untuk setiap project.
- Static generation untuk route project dinamis.
- Carousel gambar project dengan animasi.
- Form kontak menggunakan Web3Forms API.
- Vercel Analytics.
- Docker image dengan builder Node.js dan runtime Nginx.

3. ARSITEKTUR APLIKASI
----------------------

3.1 Model rendering dan routing
Project menggunakan Next.js App Router.

Route yang terdeteksi:
- /: landing page utama.
- /projects/[id]: halaman detail project dinamis.
- /projects/01 sampai /projects/05: hasil static generation dari data project.
- /_not-found: halaman fallback Next.js.

Konfigurasi penting di next.config.ts:
- output: 'export'

Konfigurasi ini membuat Next.js menghasilkan static site di folder out. Karena static export digunakan:
- Tidak ada server-side runtime Next.js pada deployment utama.
- Tidak tersedia API route Next.js pada runtime production.
- Tidak digunakan server-side database access.
- Dynamic route harus memiliki generateStaticParams, dan project ini sudah menyediakannya.

6. ARSITEKTUR DEPLOYMENT
------------------------

Pipeline deployment:

Source code
    |
    v
npm ci
    |
    v
npm run build
    |
    v
Next.js static export -> out/
    |
    v
Nginx Alpine image
    |
    v
Static HTML/CSS/JS dan asset disajikan melalui port 80

Command Docker yang sesuai:
- Build image:
  docker build -t webportofolio .
- Run container:
  docker run --rm -p 3005:80 webportofolio
- Akses aplikasi:
  http://localhost:3005

Catatan: npm run start menggunakan serve dan port 3005, sedangkan Docker menggunakan Nginx pada port container 80. Port host dapat dipetakan ke 3005 menggunakan -p 3005:80.

9. TEMUAN TEKNIS DAN RISIKO
---------------------------

Prioritas tinggi:

1. Access key Web3Forms berada langsung di source client
   Contact.tsx mengirim access_key secara hardcoded dari browser. Nilai ini tidak ditulis ulang di laporan demi menghindari penyebaran credential/token.
   Risiko:
   - Dapat terlihat oleh siapa pun melalui source bundle atau browser DevTools.
   - Jika key tersebut bersifat sensitif atau dapat disalahgunakan, perlu segera dirotasi.
   - Pertimbangkan backend/proxy atau mekanisme server-side yang sesuai. Untuk static export, proxy dapat ditempatkan di platform hosting atau service terpisah.

2. Tidak ada konfigurasi Nginx custom untuk fallback/routing
   Static export saat ini kemungkinan berjalan baik untuk URL hasil export langsung, tetapi konfigurasi Nginx default belum secara eksplisit menangani fallback route atau SPA-style routing. Karena project memiliki file HTML hasil export untuk project detail, risikonya terbatas, tetapi deep-link behavior tetap perlu diuji pada hosting target.

Prioritas menengah:

3. Error form tidak terlihat jelas oleh user
   Contact.tsx mengubah status ke error tetapi hanya menulis console.error. Tambahkan pesan error yang dapat dilihat user.

4. Aksesibilitas carousel dapat ditingkatkan
   - Komponen mengimpor Image namun menggunakan img biasa.
   - Gambar memakai object-fill yang berpotensi merusak rasio gambar.
   - Belum terlihat dukungan keyboard/gesture yang lengkap.
   - Alt text masih generik berupa Slide N.

5. Navbar mobile belum memiliki menu aktif
   Elemen [menu_sys] hanya indikator visual dan bukan tombol/menu yang dapat digunakan. Link navigasi disembunyikan pada ukuran kecil.

6. Blog belum menjadi fitur aktif
   Blog.tsx tersedia dan memiliki id blog, tetapi tidak dirender pada halaman utama. Link /blog juga belum memiliki route page.tsx yang terlihat pada source route.

7. README masih template create-next-app
   README belum menjelaskan project portfolio, command Docker, static export, struktur folder, maupun deployment.

8. Data konten masih berada langsung di component
   Data skill, metadata contact, social link, dan blog masih hardcoded pada component. Untuk project kecil ini masih wajar, tetapi pemisahan content/config akan mempermudah pemeliharaan.

9. Metadata dan bahasa dokumen belum sepenuhnya konsisten
   Metadata menyasar portfolio personal, tetapi html lang masih en. Jika target utama adalah audiens Indonesia, pertimbangkan konten bilingual atau lang yang sesuai.

10. Tidak ada test otomatis
   Saat ini tidak terlihat unit test, integration test, atau end-to-end test. Build dan lint menjadi verifikasi utama.
